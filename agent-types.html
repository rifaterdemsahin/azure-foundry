1. The 6 Major AI Agent Archetypes in Foundry

In Azure AI Foundry, an agent is more than a chatbot—it is an autonomous software entity equipped with reasoning models, persistent thread memory, and custom tool integrations (OpenAPI specs, Python Code Interpreter, Bing Search, and Azure AI Search).

📚
Enterprise Knowledge & RAG Agent

Retrieves company policies, technical manuals, internal wikis, and PDF contracts with strict citations and zero hallucination guardrails.

  • Hybrid Vector + Full-text search with semantic reranking.
  • Document level security & Entra ID ACL enforcement.
Azure AI Search GPT-4o-mini / Phi-4 Blob Storage
📊
Data Analytics & Code Execution Agent

Executes Python in secure micro-containers to analyze CSVs, generate matplotlib/seaborn charts, run statistical models, and parse log files.

  • Dynamic Python sandbox with standard data science libraries.
  • Generates downloadable reports, charts, and clean datasets.
Code Interpreter GPT-4o Azure Fabric / SQL
⚙️
Action & API Orchestration Agent

Takes real-world actions across enterprise SaaS apps (ServiceNow, Jira, Salesforce, Stripe, SAP) by interpreting OpenAPI Swagger specifications.

  • Reads Swagger endpoints and auto-generates REST calls.
  • Handles user authentication via Managed Identity / OAuth2.
OpenAPI Tools GPT-4o-mini Azure Logic Apps
🤖🤝🤖
Collaborative Multi-Agent Swarm

A coordinator agent orchestrates specialized sub-agents (e.g. Researcher + Writer + Reviewer + Fact Checker) using Microsoft AutoGen or Semantic Kernel.

  • Hierarchical delegation and group-chat consensus loops.
  • Separation of concerns between planning and tool execution.
AutoGen / Semantic Kernel o3-mini / GPT-4o
🌐
Live Web Research & Market Intelligence

Monitors competitor pricing, financial news, regulation filings, and live web data using real-time Bing search grounding.

  • Real-time web browsing with domain-filtered search queries.
  • Automated multi-source synthesis and fact cross-checking.
Bing Search Tool GPT-4o Content Safety
🚀
DevOps & Issue Triage Bot

Asynchronously monitors GitHub / Azure DevOps issues, summarizes bug stack traces, proposes automated PR diffs, and triages alerts.

  • GitHub REST API integration to comment and create PRs.
  • Triggers automatically on webhook alerts without human standby.
GitHub REST API GPT-4o-mini / o3-mini App Insights

2. Orchestration Frameworks Supported in Foundry

Azure AI Foundry is framework-agnostic. You can deploy and orchestrate agents using:

Framework Best Suited For Foundry Integration Method
Azure AI Agent Service (Native) Out-of-the-box stateful agents with managed threads, built-in Code Interpreter, Bing Search, and Azure AI Search. Native Portal & SDK Python / C# / REST
Microsoft AutoGen Complex multi-agent conversations, group chats, debate systems, and autonomous problem solvers. Azure AI Model Catalog OpenAI/DeepSeek endpoints
Microsoft Semantic Kernel Enterprise C# and Python applications requiring strict plugins, filters, memory stores, and planners. Native Azure Connector Enterprise SDK
LangChain & LlamaIndex Community pipelines, advanced RAG chunking strategies, and multi-vector retrieval algorithms. Azure OpenAI / AI Search Native integrations

3. Quick Architecture Recommendation

Where should you start?
Start with the Native Azure AI Agent Service in the Foundry portal. It gives you instant access to multi-model switching, serverless Code Interpreter, Bing Search grounding, and thread persistence with zero server provisioning!
